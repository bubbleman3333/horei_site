# 解説記事の置き場

`data/articles/<法令ID>.md` を置くと、その法令のページの本文が自動生成の文章から置き換わる。
法令 ID は `data/laws/<法令ID>.json` のファイル名（例: `322AC0000000049` = 労働基準法）。

書いていない法令はデータから自動で組み立てた文章が入るので、全部書く必要はない。
まだ書かれていない法令は `python -m horei pending` で出せる（施行予定が近い順）。

## 形式

```markdown
---
title: 労働基準法の改正で何が変わるか
summary: 2027年4月1日施行の改正で、◯◯が変わります。総務・人事が先に確認すべき点をまとめました。
---

## 何が変わるのか

本文を Markdown で書く。見出しは `##`（h2）から。

## いつから変わるのか

- 表も使える
- 箇条書きも使える
```

`title` はページの h1 と `<title>` に、`summary` は説明文（meta description・RSS・一覧）に使われる。
どちらも省略すると、法令名とデータから作った 1 行が入る。

## 書くときの注意

- 法令の解釈や「こうすべき」という助言は、書くなら根拠を示す。断定を避ける。
- 条文を引くときは e-Gov 法令検索の原文に当たる。法令ページ下部の改正履歴の表が手がかりになる。
- `python -m horei digest <法令ID>` で、その法令のデータを要約したテキストが出る。
